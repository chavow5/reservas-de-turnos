# ⚽ Sistema de Reservas de Turnos para Canchas y Complejos Deportivos

Sistema moderno, optimizado y listo para producción para gestión y cobro de turnos de canchas de fútbol y deportes.

## 🚀 Puesta en Marcha Rápida (Local)

### 1. Backend
```bash
cd backend
npm install
# Copiar variables de entorno
cp .env.example .env
# Iniciar servidor
npm start
```

### 2. Frontend
```bash
cd frontend
npm install
# Copiar variables de entorno
cp .env.example .env
# Iniciar cliente
npm run dev
```

### 3. Tests
```bash
cd backend
npm test
```
